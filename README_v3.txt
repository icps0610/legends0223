Anonymizer（iPhone Safari 相容版 V3）

檔案：anonymizer_email_keywords_v3.html（單一 HTML，不需安裝）

本版修正：
- 原始文字欄使用真正的標準 textarea，不再用絕對定位/覆蓋層。
- 支援系統長按貼上；追加 paste/input/change 事件偵測。
- 新增「處理文字」手動執行按鈕。
- 新增「程式已啟動」狀態；如未啟動，請注意 HTML 預覽可能停用 JavaScript。
- 「從剪貼簿貼上」按鈕僅在 Safari 允許剪貼簿讀取的安全環境有效，不保證 iOS 本機檔案有效；請優先使用系統長按貼上。

使用方法：
1. 打開 HTML，首先確認頂部顯示「程式已啟動」。
2. 點一下「① 原始文字」下方白色輸入框，長按選擇「貼上」。
3. 若無文字，先按「範例」確認程式碼執行；再試直接打字確認可以輸入。
4. 若頂部持續顯示「程式尚未啟動」，可能正在使用 iPhone 檔案預覽（Quick Look），該預覽可能不執行 JavaScript。可將檔案部署至 HTTPS 網址後用 Safari 開啟。
5. 「設定與關鍵字」支援自訂逗號或換行分隔的敏感文字；預設自動遮蔽僅 Email。

隱私：無第三方資源依賴，程式在瀏覽器本機執行。瀏覽器可以在使用者勾選時於 localStorage 保存對照表；否則不主動保存對照表。匯出對照表內含原始敏感文字，請妥善保管。

測試：已以 Chromium 手機尺寸模擬確認一般輸入、Email 和自訂關鍵字遮蔽、處理文字及範例按鈕；尚未於實體 iPhone Safari 測試。
